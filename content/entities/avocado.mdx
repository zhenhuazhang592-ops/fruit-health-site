## Overview

牛油果（Persea americana）是一种原产于中美洲的热带水果，以高脂肪含量和独特绵密口感著称。在全球健康饮食风潮中曾被冠以"超级食物"标签，但实际上属于高热量水果，其核心营养价值在于提供优质单不饱和脂肪。

## Key Facts

- **热量**：160 kcal / 100g（一颗中等牛油果约240 kcal）
- **脂肪**：14.7g / 100g（以油酸为主的单不饱和脂肪酸）
- **膳食纤维**：6.8g / 100g（约占每日推荐量27%）
- **钾**：975mg / 100g（约占每日推荐量20%）
- **蛋白质**：仅 2g / 100g（极低，非蛋白质来源）
- **品种差异**：哈斯（Hass）与富尔特（Fuerte）在营养成分上无临床显著差异
- **"超级食物"标签**：市场营销概念，缺乏科学定义

## 营养价值评估

| 维度 | 评估 |
|------|------|
| 膳食纤维密度 | 高（在水果中突出） |
| 钾含量 | 高 |
| 蛋白质密度 | 极低 |
| 热量密度 | 高（需控量） |
| 性价比 | 中等（可用其他食材替代） |

## 核心价值

**饱和脂肪替代品**：用牛油果替代黄油、蛋黄酱等饱和脂肪来源，才是其真正价值所在。

## 关键洞察

1. **脂肪类型以单不饱和脂肪酸（油酸）为主**，对心血管友好
2. **膳食纤维含量在水果中属于高水平**，有助于肠道健康
3. **钾含量突出**，有助于维持电解质平衡
4. **蛋白质极低**，不适合作为蛋白质来源
5. **热量高**，需严格控制摄入量
